O que mudou nos tokens
--background
0.165 → 0.155 · mais um degrau de elevação
--primary
fill · texto branco a 5.15:1 (era 4.34:1)
--primary-text
novo · acento como texto, 6.59:1
  • Acento dividido. O token único do repo é usado ao mesmo tempo como fundo de botão e como cor de texto; nos dois papéis ele não passa em 4.5:1. Agora são dois tokens com um papel cada.
  • Hover escurece. Clarear o primário no hover derrubaria o contraste do texto branco para 3.99:1, então o hover vai para L 0.47 mais um anel — o contraste sobe.
  • Mono como registro. Geist Mono carrega id, contagem e rótulo de seção; Geist Sans carrega leitura. É o par que o repo já instala.
  • Sem fotos. Assignee é monograma sobre superfície neutra — coerente com um app local que lê nomes do bd, não um diretório de pessoas.
