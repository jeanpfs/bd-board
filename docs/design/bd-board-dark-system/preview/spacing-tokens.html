A 2px scale for a tool that stays open all day

The useful range is 2 → 28px. Steps sit close together because the board is dense on purpose: a bead card is 9×10px of padding, four columns share a 12px gutter, and the largest component gap in the system is the 26px between sections inside the detail sheet.

The rail brand row and the topbar are both 48px, so the horizontal rule crosses the whole window unbroken. That single alignment is what makes the split shell read as one surface.
