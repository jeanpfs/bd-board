Buttons, navigation and controls

Every interactive state is rendered side by side, because the rule that governs them is easy to break: the background moves and the foreground brightens. Nothing here dims text on hover, and no fill is ever lightened.

Action economy

One filled button per surface. The whole board has exactly one — New bead. The detail sheet has exactly one — Comment. Everything else is outline, ghost or a text link, including the close and edit affordances in the sheet header.
