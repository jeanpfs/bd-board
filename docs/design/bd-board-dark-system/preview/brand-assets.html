The mark, the icon set, the monogram

This product's identity is small and deliberate: one 24px gradient mark, one monoline icon vocabulary, and monograms instead of photographs. Everything below is extracted from the source — nothing was redrawn.

Brand mark and wordmark
bd bd bd bd board Write mode JP

The mark is CSS, not an image: linear-gradient(160deg, var(--primary-text), var(--primary-hover)) on a 7px rounded square with mono 600 lettering. It is the only gradient in the entire system — that is the whole flourish budget. The wordmark is bd board, 13px, 600, −0.01em, always lowercase.

Not available in the source evidence: there is no app icon, tray icon, installer artwork or favicon. The sample dataset contains an open bead about exactly this — bdb-p2m · "Replace the scaffold icons with project artwork" — so the project has not produced them yet. None were invented here.

Icon set — 27 glyphs, one contract

24×24 viewBox · no fill · stroke: currentColor · stroke-width: 1.7 · round caps and joins · aria-hidden, with the label on the surrounding control. Rendered here by build/icons.js; each also exists standalone under assets/icons/, indexed in manifest.json.

One family, no exceptions. There are no filled glyphs, no second icon library and no emoji used as icons anywhere in this product.

Each chip opens the preserved file itself. The small glyph inside is painted by masking that same SVG with currentColor — the exact contract the runtime uses, proven against the file on disk rather than against a copy pasted into this page.

Optical sizes in use

Size is passed per call, never baked into the path. The practical range is 11–15px: 11–12px inside chips and stat clusters, 13px in buttons and section heads, 14px in rail items and the topbar, 15px for the lane disclosure chevron.

Monograms — the avatar system

A monogram plate — 19px, wash 9%, --border-strong ring, mono 9px initials, with a 26px variant in the detail sheet. Initials come from splitting the identifier on [\s_@.-], so an email and an agent name both resolve.

From the redesign's own notes: "Sem fotos. Assignee é monograma sobre superfície neutra — coerente com um app local que lê nomes do bd, não um diretório de pessoas." There is no image avatar in this system, and adding one would be a lie about where the names come from.
