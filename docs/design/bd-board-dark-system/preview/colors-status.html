Status columns and the knowledge taxonomy

Two categorical sets. Four status hues drive the board columns, the stacked bar and the completion ring; seven taxonomy hues label the knowledge prefixes. Neither set is ever the only channel — every mark carries its label in text.

Open is near-neutral on purpose. "Not started" is not a state worth spending a hue on; the colour budget goes to work that is moving, stuck, or done. --warn (oklch(0.8 0.15 85)) is separate and belongs to the P1 chip and the Pinned tag, not to a column.

Segment order is fixed: closed → in progress → blocked → open, so the finished share always reads from the left edge. Every gauge uses a filled encoding; there is no outline-only chart in the system.

All seven sit at L 0.75 ± 0.04 so every hue clears 7:1 on --card. Consumers derive the chip tint and ring from the one hue — color-mix(in oklch, var(--k) 15%, transparent) for the fill, 38% for the ring — so a new type needs exactly one new value.
