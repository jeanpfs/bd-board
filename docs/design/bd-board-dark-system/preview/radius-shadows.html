Preview 05 · Radius, elevation, motion

Corners track size, outlines are rings

The radius ladder is not decorative: it runs from 4px on a priority chip to 14px on the detail sheet, and the step is a function of the object's size. Every outline is an inset box-shadow, so it composes with elevation and hover without a layout shift.

Pills at 999px are reserved for things that are not boxes: status dots, filter chips, the progress bar, the avatar plate.

Hover — background moves, foreground never dims
bdb-h4w P2 3d Debounce the search input against the URL router CC bdb-h4w P2 3d Debounce the search input against the URL router CC

Rest → hover changes three things together: surface 0.208 → 0.246, ring 9% white → accent 45%, and a −1px lift with --lift-card. The text is untouched. No state in this system fades a foreground toward the background — disabled is the only exception, and it lives on one button.

Motion
120msNav, buttons, chips, menu items, inputs, selects — colour only
140msCards that also lift 1–2px: bead, project, overview
160msLane disclosure chevron rotation
400msProgress bar segment width — only when the value actually changes

Everything is ease. Nothing animates layout size. prefers-reduced-motion: reduce collapses every duration to 0.01ms, which is already in assets/bd-dark.css — inherit it, do not reimplement it.
