Buttons — one primary per surface
Write mode

New bead is the only filled button on this surface. Click it: the label swaps to the command it would run, which is the pattern the board uses instead of an optimistic spinner.

Search — 30px, wash 5%, slash to focus

no query

Focus swaps the inset ring to --ring and the fill to wash 8%. The / chip disappears once the field has a value, so it never sits behind text.

Segmented, chips and menus

The menu tick uses visibility: hidden rather than removal, so rows never shift as you toggle. An open trigger keeps [aria-expanded="true"], which is styled to wash 8% — the button stays visibly engaged while its menu is up.
