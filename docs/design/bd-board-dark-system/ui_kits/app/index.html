Non-negotiables when extending the kit
  • Two accent tokens, two roles. --primary fills, --primary-text writes. Never swap them.
  • Hover darkens the fill. Lightening the primary drops white text to 3.99:1. Go to L 0.47 and add a ring.
  • One filled button per surface. Everything else is outline, ghost or a text link.
  • Outlines are inset rings, not border, so they compose with elevation.
  • Hue is never the only channel. Every dot, chip and tag also carries its label.
  • Mono is the machine register. Ids, counts, durations and bd commands — always tabular.
  • Preview the command. Any surface that mutates shows the bd call it will make.
  • Only .canvas scrolls. Rail, topbar and filter bar are flex: none.
