    Project rail

    Fixed --rail width (232px) on --sidebar, one elevation step above the page. Three stacked groups — projects, views, quick filters — separated by 18px, each with a mono uppercase label.

    The brand row is 48px, exactly matching the topbar, so the horizontal rule crosses the window unbroken. Only .rail-scroll scrolls; the brand row and the version foot are flex: none.

    A row is .rail-item: rest is --muted-foreground, hover adds a 6% wash and full-strength text, active adds an 8% wash plus an inset ring. The trailing .count brightens with the row rather than staying dim.

    Mark the current page with aria-current="page" — the stylesheet styles that attribute directly, so no extra class is needed.
