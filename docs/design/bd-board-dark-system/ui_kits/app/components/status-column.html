Component · status column + swimlane

Four columns, grouped into lanes

The header row is position: sticky; top: 0 over the scrolling canvas, filled at 92% opacity with backdrop-filter: blur(8px), so cards pass underneath it instead of colliding with it. Scroll this page to see it hold.

Each header carries a coloured dot, a 12.5px label and a mono count in the status colour. A lane is a header plus a four-cell grid at a 12px gutter; the chevron rotates −90° when data-open="false" and the grid is hidden.

Lane meta shows a stacked progress bar and a done/total ratio. Below 1240px the bar drops via .hide-sm and the ratio stays — the number survives, the decoration does not.
