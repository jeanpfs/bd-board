Topbar and filter bar

48px tall on --background, matching the sidebar brand row exactly. Left to right: breadcrumbs, view tabs, then a right-aligned end cluster carrying the mode badge and the identity monogram.

The selected tab carries three signals at once — full-strength text, weight 550, and a 2px --primary-text underline. The tab set is mirrored in the sidebar, and both must be driven from one state value so they cannot disagree.

The mode badge is identity, not chrome. This app can mutate real repositories, so which mode it is in is the single most important thing the interface asserts about itself. It never scrolls away.

The filter bar sits directly below at 8px 16px and wraps. It holds exactly one filled button — New bead — and every other control is a segment, chip, or outline button.
