Comment composer

A 9px textarea on a 5% wash with an inset ring, a right-aligned primary button, and a live bd command preview. This is the only filled button on the detail sheet.

Submit stays disabled until there is something to submit. The button enables on the first non-whitespace character and disables again after posting — no spinner, no optimistic toast.

The composer is also how knowledge gets written. There is no knowledge entity in bd: an entry is an ordinary comment whose text opens with one of seven recognised prefixes. Type DECISION:, LEARNED:, FACT:, PATTERN:, INVESTIGATION:, MUST-CHECK: or DEVIATION: and the field acknowledges the type before you post.

The command preview updates as you type. Any surface that mutates state shows the exact bd call it will make — the app shells out to a real binary against real repositories, and it says so first.
