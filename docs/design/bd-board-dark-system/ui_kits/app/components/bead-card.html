Bead card

--card at 8px radius with 9px 10px padding, an inset ring and --shadow-card. Always three rows, always in the same order, so a column of them scans vertically.

.bead ├ .bead-top id · P-chip · state tag · relative age ├ .bead-title 12.75px, 2-line clamp └ .bead-foot label chips · stat cluster · assignee monogram

The stat cluster is mono and tabular: subtasks, blocked-by (in --status-blocked), blocking, related, comments. Counts that are zero are omitted entirely rather than shown as 0.

An epic adds .is-epic — a 2px --primary-text left border with tightened left corners — and a stacked progress bar summarising its children.

Hover changes three things together: surface 0.208 → 0.246, ring 9% white → accent 45%, and a −1px lift. The text is untouched.

Cards live inside a .lane-cell — a recessed --canvas well at 10px radius — so they read as sitting in a column rather than floating on the page. An empty cell shows an em dash, never a blank box.
